Hub + sub-pages pattern 首页 + 子页面 模式

When an HTML artifact grows past one page, give it a hub:

当一个 HTML artifact 超过单页时，提供一个首页：

  • The hub indexes all sub-pages with previews, short descriptions, and direct links.
  • Each card offers both Open inline (iframe preview without leaving the hub) and Open standalone (new tab) so reviewers can stay in context or copy a link.
  • Every sub-page renders a Back to gallery (or Back to home) link in its topbar, and hides it automatically when embedded in an iframe so the parent UI is not duplicated.
  • Both the hub and each sub-page keep the same language switch, the same fonts, and the same export controls so navigating between them feels continuous.
  • 首页（hub）索引所有子页面，并提供预览图、简要说明和直达链接。
  • 每张卡片同时提供 嵌入预览（在首页内 iframe 加载）和 独立打开（新标签页），让评审者既可以保持上下文，也可以拷贝独立链接。
  • 每个子页面顶部都有 返回 gallery（或 返回首页）链接；当被 iframe 嵌入时自动隐藏，避免与父页 UI 重复。
  • 首页和子页面共享相同的语言切换、字体和导出控件，让在它们之间跳转感觉连续。
