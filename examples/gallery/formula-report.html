Specificity-safe Match F1

Use this for evaluator quality when broad matches should be penalized.

TP=|{ g in G : exists l in L, match(g,l) and specific(l,g) and supported(l) }|
FP=|{ l in L : claimed_match(l) and invalid_or_overbroad(l) }|
Precision=TP / (TP + FP)
Recall=TP / |G|
F1=2 x Precision x Recall / (Precision + Recall)

Gate: BroadOvercreditRate <= 0.05.

Expansion Coverage Yield

Use this for section expanders that add leaves under a fixed budget.

DeltaCovered=|Covered(L_after) \\ Covered(L_before)|
AddedLeaves=|L_after \\ L_before|
SpecificityMean=mean_l_in_DeltaL specificity_score(l)
Yield=(DeltaCovered / AddedLeaves) x SpecificityMean x (1 - UnsupportedRate)

Gate: ExpansionYield >= 0.25.
